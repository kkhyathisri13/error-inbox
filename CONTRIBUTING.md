# Team Collaboration Guidelines

## Review Processes
- All pull requests require at least one peer review before merging.
- Code reviews should focus on readability, maintainability, and architectural consistency.

## Communication Channels
- Use our primary Slack channel for daily syncs, quick questions, and general updates.
- Use GitHub issues for tracking bugs, features, and administrative tasks.

## Milestone Expectations
- Tasks should be kept up to date on project boards and tagged appropriately (e.g., `administrative`, `documentation`).
